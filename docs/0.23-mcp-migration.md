# MCP 0.23 plugin migration

Version 0.23 moves final pricing ownership fully into Savoya MCP/Core while preserving the plugin's rate-sheet question, document UX, flight-time construction, capture workflow, client cache, and export formats.

## What changed

- Removed active use of the approximate planner and single-vehicle option tool.
- Selected packages use `calculate_quote_units`; comparisons use `generate_quote_options`; temporary rates/discounts use `calculate_temporary_quote_units`.
- Passenger IDs are sent only for named passengers. Passenger count remains required for Core capacity sizing.
- Vehicle IDs/capacities come from live Core data, not a plugin catalog.
- Handoff contract v3 stores the selected raw result and its reproducible source request.
- A document-stage whole-percentage discount re-quotes the complete selected package through MCP. Removing it returns to the ordinary tool unless temporary rates remain.
- The document layer copies returned rates, quantities, subtotals, discounts, line totals, and aggregate totals by field presence. It does not calculate money.
- Fuel overrides/waivers and priced greeter fees are unsupported; existing Core facts remain visible and operational additions can be non-priced notes.
- One complete Core option must be selected before export; synthetic Option B documents were removed.

## Safety guarantees

- Only exact, complete, `persisted: false` results enter document generation.
- Temporary quote pricing cannot be sent into a reservation/application workflow by this plugin.
- Mixed temporary packages are rejected instead of merged locally.
- Verification compares copied values directly with the authoritative raw response and does not assume aggregate total equals the sum of line totals.

## Environment configuration

Acceptance remains `https://mcp-acceptance.savoya.net/mcp`. `rebuild_plugin.py --mcp-url <public-url>` changes only the packaged build for local testing. Claude cannot reach localhost. The tunnel host must match `SAVOYA_MCP_PUBLIC_URL` and the Auth0 audience. Clear plugin caches, reconnect OAuth, and use a new conversation whenever environments change.

## Historical compatibility

Archived feedback may retain old tool names as historical context. No active skill, script, evaluation, or user-facing documentation should route to them.
